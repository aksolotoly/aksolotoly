# Своё Дело — Telegram-бот

7-дневный помощник для плавной смены профессионального направления: тесты, ранние воспоминания, Икигай, идеи направлений и первые шаги. Генерирует PDF-отчёт.

## Запуск

1. Создайте бота через BotFather и получите токен.
2. Скопируйте `.env.example` в `.env` и вставьте токен:
   
   ```bash
   cp .env.example .env
   echo "BOT_TOKEN=123456:ABC..." >> .env
   ```
3. Установите зависимости и запустите:
   
   ```bash
   npm i
   npm run dev
   ```

## Команды
- /start — онбординг и старт/продолжение дня
- /continue — продолжить с текущего шага
- /report — сгенерировать PDF-отчёт

## Структура
- `src/index.js` — вход, команды, диалоги
- `src/content.js` — тексты и шаги по дням
- `src/db.js` — SQLite (better-sqlite3), таблицы и DAO
- `src/report.js` — генерация PDF отчёта
- `data/` — база `bot.db`
- `reports/` — PDF отчёты
